# Stick War Clone

Клон игры Stick War Legacy, написанный на **JavaScript** с использованием HTML5 Canvas.

## Как запустить

1. Откройте файл `index.html` в любом современном браузере
2. Или используйте локальный сервер:
   ```bash
   python -m http.server 8000
   ```
   Затем откройте `http://localhost:8000`

## Управление

- Кнопки внизу экрана для создания юнитов:
  - ⛏️ **Шахтёр** (50💰) - добывает золото из шахт
  - ⚔️ **Мечник** (100💰) - базовый боец
  - 🏹 **Лучник** (150💰) - атакует издалека
  - 🗿 **Гигант** (300💰) - много здоровья и урона

## Особенности

- Пассивная генерация золота
- Захват золотых шахт для дополнительного дохода
- Волны врагов с нарастающей сложностью
- Различные типы юнитов с уникальными характеристиками
- Система победы/поражения

## Язык программирования

**JavaScript** - выбран по следующим причинам:
- Работает прямо в браузере без установки дополнительных программ
- HTML5 Canvas предоставляет отличные возможности для 2D игр
- Быстрая разработка и прототипирование
- Кроссплатформенность
